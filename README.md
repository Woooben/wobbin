# Wobbin

A private UI reference library inspired by Mobbin.

## Current features

- App package library
- Screens / Flows / UI Elements browsing
- Folder, multi-image and ZIP import
- Cover selection
- Single and batch screenshot deletion
- App package deletion
- Dark / light mode
- App Store logo lookup
- Local IndexedDB storage

## Deployment

This repository is ready for static deployment on Vercel. Cloud sync with Supabase is the next step.
